\noindent\textbf{Response to the Associate Editor.}
Thank you for identifying the remaining discrepancy between the algorithm
and its implementation. We have revised the optimizer to evaluate the
profiled objective in Equation~(4) explicitly, including the $1/(2n)$
scaling, the signed mediation-proportion term, and both sparsity penalties.
The implementation now constructs a feasible initialization and checks
$\widehat\tau(a)\ge r_0$ and
$1-\widehat\alpha(a,b)^2\ge\delta$, together with the normalization
constraints, after each proposed loading update. Infeasible trial steps
are rejected and backtracked; the auxiliary and dual updates hold the
accepted loading pair fixed. The code records feasibility margins,
rejected trials, objective values, and ADMM residuals.

We have also clarified immediately after Theorem~1 that its conclusions
are conditional on the stated assumptions. The numerical implementation
uses approximate constrained block updates, and the sufficient-decrease,
relative-error, and additional geometric conditions have not been verified
for that implementation. Enforcing feasibility does not establish these
conditions. We therefore do not claim that the theorem provides an
unconditional convergence guarantee for the implemented algorithm, or
that the code changes leave the reported numerical results unchanged.
